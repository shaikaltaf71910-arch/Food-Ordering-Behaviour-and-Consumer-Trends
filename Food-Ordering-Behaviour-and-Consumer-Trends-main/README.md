# 🍽️ Food Ordering Behaviour and Consumer Trends Dashboard

## 📌 Project Overview

This project is an interactive **Tableau Dashboard** that analyzes food ordering behaviour and consumer trends using historical order data. It converts raw data into visual insights covering customer preferences, cuisine/meal demand, revenue, ratings, and payment behaviour — helping restaurants and food delivery businesses make data-driven decisions.

A **Tableau Story** is also included to walk through the key findings step by step.

---

## 🎯 Objectives

- Analyze customer ordering behaviour
- Monitor business performance using KPIs
- Evaluate customer satisfaction through ratings
- Study meal type preferences
- Analyze payment method trends
- Support informed decision-making using interactive dashboards

---

## 🛠️ Technology Stack

- **Data Source:** Food Ordering Behaviour dataset (CSV/Excel)
- **Data Preparation:** Microsoft Excel
- **Visualization Tool:** Tableau Desktop / Tableau Public
- **Dashboard Components:** KPI Cards, Bar Charts, Pie Charts, Line Charts, Donut Charts, Filters, Highlight Actions

---

## 📊 Dashboard Features

**KPIs**
- Total Orders
- Total Order Value (Revenue)
- Delivery Fee
- Average Customer Rating

**Visual Insights**
- Meal type distribution (Bar Chart)
- Payment method preference (Pie Chart)
- Order trends over time (Line Chart)
- Customer rating distribution
- Interactive filters for customer segment comparison
